## ✅ الخطوات المتبقية لتفعيل الموقع

### 1️⃣ رفع صور المنتجات

الموقع يحتاج صور المنتجات في مجلد `images/`. لديك خياران:

**الخيار أ: رفع يدوي عبر GitHub**
1. اذهب إلى https://github.com/aladalah2026-gif/almanalcouture.com
2. اضغط على **"Add file" → "Upload files"**
3. اسحب مجلد `images/` كاملاً (21 صورة)
4. اضغط **"Commit changes"**

**الخيار ب: استخدام GitHub Desktop**
1. حمّل GitHub Desktop من https://desktop.github.com
2. استنسخ (Clone) هذا المستودع
3. انسخ مجلد `images/` إلى المشروع المحلي
4. اضغط **"Commit to main"** ثم **"Push origin"**

### 2️⃣ تفعيل GitHub Pages

1. اذهب إلى **Settings** في المستودع
2. اذهب إلى **Pages** من القائمة اليسرى
3. في قسم **Source** اختر:
   - Branch: `main`
   - Folder: `/ (root)`
4. اضغط **Save**
5. انتظر 2-5 دقائق ثم زر: `https://almanalcouture.com`

### 3️⃣ ربط الدومين (تم بالفعل ✅)

ملف `CNAME` موجود بالفعل ويحتوي على `almanalcouture.com`.

تأكد من أن إعدادات DNS في Namecheap تُشير إلى GitHub:
